# AHP Matrix — Plan 2: Web UI

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The browser UI that `ahp-matrix` serves:
- a library of decisions
- setup, with options, a criteria tree, people and the scale
- comparing in pairs on a balance beam, plus a grid view, with live consistency feedback
- rating and measured-value scoring
- results, what-if sensitivity, and a printable report

All of it is built into the binary.

**Architecture:**
- **App:** a Svelte 5 single-page app in `web/`, built by Vite into `web/dist` (which Plan 1's `web.FS()` embeds).
- **Pure logic in `web/src/lib`**, unit-tested with Vitest: tree and judgment edits, pair order, progress, and a TypeScript copy of the Go sensitivity math. That copy is held to Go by golden files Go writes.
- **`ProjectSession`** owns one open project: debounced autosave, version conflicts, results refresh.
- **Components** are tested by server-side rendering in Vitest, and the screens by Playwright against the real binary.

**Tech Stack:**
- Svelte 5.57, Vite 7.3, TypeScript 5.9, svelte-check 4.7
- Vitest 4.1, Playwright 1.64
- @fontsource-variable (Bricolage Grotesque, Hanken Grotesk)
- Go for the golden files and security headers

No CSS framework.

**Spec:** `docs/superpowers/specs/2026-10-15-ahp-matrix-design.md` (§8 UI, §10 Testing). Plan 1 (`docs/superpowers/plans/2026-10-15-plan-1-engine-api-cli.md`) supplies the API this plan consumes.

All code below was built, type-checked, unit-tested and end-to-end tested, and the running app was reviewed in a browser in light, dark and phone layouts, before this plan was written.

## Global Constraints

- **Node 20.19+.** The versions in `web/package.json` are as given. `npm ci` must work from the committed `package-lock.json`.
- **Clean on every change:** `npm run check` (svelte-check, no errors or warnings), `npm test` (Vitest), `make lint`, `make test`.
- **The UI talks only to the same-origin API from Plan 1.** No CDNs or remote fonts: everything is bundled.
- **The JSON field names in `web/src/lib/types.ts`** mirror `internal/model` and `internal/server` exactly.
- **Design tokens** live in `web/src/app.css`:
  - fog/paper surfaces, slate ink, a brass accent, rust only for contradictions
  - alternative colors are the validated categorical palette, stored on each alternative as `series-1`…`series-8` (light and dark steps per slot)
- **Copy:** sentence case and active voice. Errors say what happened and what to do next. No all-caps labels.
- **Layout:** works at 390 px wide with no sideways scrolling. Keyboard focus is visible, and reduced motion is respected.
- **The server sends security headers:** `X-Frame-Options: DENY`, plus a Content-Security-Policy that allows only `'self'` (inline styles are allowed).

## Spec refinements made while planning

- **Plain CSS instead of Tailwind.** Design tokens are CSS custom properties and each component's CSS is scoped. The look is bespoke, which utility classes don't help with, and it's one less dependency.
- **Different charts:**
  - **Weights** use an indented table with bars instead of a sunburst. It's easier to read and accessible as a table.
  - **"Score breakdown"** is a contribution matrix (option × leaf criterion, weight × priority). It replaces stacked bars, which would have needed a second categorical palette alongside the alternatives' colors. It's also the original spreadsheet's summary grid, drawn.
- **Alternative colors are slot names** (`series-3`), not hex values, so each one follows light and dark mode. Hex values are still accepted.
- **Pair order in the one-pair view:** first a chain that links every item (so results exist after n−1 answers), then the remaining pairs, those closest in current weight first.
- **Clickjacking protection moves into this plan:** `X-Frame-Options` and the CSP. It was a deferred minor from Plan 1's review, and it matters now that there's a UI to frame.
- **Balance keys:** ←/→ tip the balance one step, Home/End go to the extremes, `=` sets equal, and Backspace clears. These replace the spec's "1–9 to set", which can't say which side the number favours.
- **Library sorting:** the library is always sorted by last edit, and a search box appears once there are more than six decisions, instead of a separate sort control.
- **Samples, templates and Excel stay in Plan 3.** The empty library offers "New decision" and "Import file".

```ts
import type { Scale } from './types';

/** The values a judgment may take on a scale, ascending (mirrors model.Scale.Allowed). */
export function stops(scale: Scale): number[] {
  if (scale === 'classic5') return [0.1, 0.2, 1, 5, 10];
  const out: number[] = [];
  for (let k = 9; k >= 2; k--) out.push(1 / k);
  for (let k = 1; k <= 9; k++) out.push(k);
  return out;
}

/** The allowed value closest to v on a log scale. */
export function snap(v: number, scale: Scale): number {
  let best = 1;
  let bestDist = Infinity;
  for (const s of stops(scale)) {
    const d = Math.abs(Math.log(s) - Math.log(v));
    if (d < bestDist) [best, bestDist] = [s, d];
  }
  return best;
}

/** Index of v in stops(scale), after snapping. */
export function stopIndex(v: number, scale: Scale): number {
  return stops(scale).indexOf(snap(v, scale));
}

const saatyWords: Record<number, string> = {
  2: 'slightly',
  3: 'moderately',
  4: 'moderately to strongly',
  5: 'strongly',
  6: 'strongly to very strongly',
  7: 'very strongly',
  8: 'very to extremely',
  9: 'extremely',
};

const classicWords: Record<number, string> = { 5: 'somewhat', 10: 'much' };

/** How strongly a value ≥ 1 prefers one side, as a word ("strongly"). */
export function strength(v: number, scale: Scale): string {
  const k = Math.round(v);
  return (scale === 'classic5' ? classicWords : saatyWords)[k] ?? '';
}

export type CompareKind = 'criteria' | 'alternatives';

/**
 * A sentence describing a judgment that a is preferred over b by v, such as
 * "Cost matters strongly more than Speed" or "Alpha is moderately better than
 * Beta on Price".
 */
export function describe(v: number, scale: Scale, kind: CompareKind, a: string, b: string, on?: string): string {
  const s = snap(v, scale);
  if (s === 1) {
    return kind === 'criteria' ? `${a} and ${b} matter equally` : `${a} and ${b} are equal${on ? ` on ${on}` : ''}`;
  }
  const [hi, lo, k] = s > 1 ? [a, b, s] : [b, a, 1 / s];
  const w = strength(k, scale);
  return kind === 'criteria'
    ? `${hi} matters ${w} more than ${lo}`
    : `${hi} is ${w} better than ${lo}${on ? ` on ${on}` : ''}`;
}

/** Formats a judgment value as people write it: 5, 1/5, 1. */
export function fraction(v: number): string {
  if (v >= 1) return String(Math.round(v * 100) / 100);
  const inv = Math.round(1 / v);
  return Math.abs(1 / inv - v) < 1e-9 ? `1/${inv}` : String(Math.round(v * 100) / 100);
}
```

```ts
/** 0.4567 → "45.7%"; values under 10% keep one decimal, larger ones too, for comparability. */
export const percent = (x: number, digits = 1) => `${(x * 100).toFixed(digits)}%`;

/** A CSS color for an alternative's stored color: a series slot ("series-3") or a hex value. */
export function colorOf(color: string): string {
  if (/^series-[1-8]$/.test(color)) return `var(--${color})`;
  if (/^#[0-9a-f]{3,8}$/i.test(color)) return color;
  return 'var(--series-none)';
}

/** "just now", "5 minutes ago", "yesterday", "3 Mar". */
export function relativeTime(iso: string, now = Date.now()): string {
  const t = Date.parse(iso);
  if (Number.isNaN(t)) return '';
  const s = Math.round((now - t) / 1000);
  if (s < 60) return 'just now';
  const m = Math.round(s / 60);
  if (m < 60) return `${m} minute${m === 1 ? '' : 's'} ago`;
  const h = Math.round(m / 60);
  if (h < 24) return `${h} hour${h === 1 ? '' : 's'} ago`;
  const d = Math.round(h / 24);
  if (d === 1) return 'yesterday';
  if (d < 7) return `${d} days ago`;
  return new Date(t).toLocaleDateString(undefined, { day: 'numeric', month: 'short', year: d > 300 ? 'numeric' : undefined });
}
```

```ts
import type { Criterion, Project } from './types';

/** Children of parentId ('' for the top level), in project order. */
export function childrenOf(p: Project, parentId = ''): Criterion[] {
  return p.criteria.filter((c) => (c.parentId ?? '') === parentId);
}

export function isLeaf(p: Project, id: string): boolean {
  return !p.criteria.some((c) => c.parentId === id);
}

/** All criteria in depth-first order with their depth (0 = top level). */
export function flatten(p: Project): { criterion: Criterion; depth: number }[] {
  const out: { criterion: Criterion; depth: number }[] = [];
  const walk = (parentId: string, depth: number) => {
    for (const c of childrenOf(p, parentId)) {
      out.push({ criterion: c, depth });
      walk(c.id, depth + 1);
    }
  };
  walk('', 0);
  return out;
}

/** Leaf criteria in depth-first order: the ones that score alternatives. */
export function leaves(p: Project): Criterion[] {
  return flatten(p)
    .map((f) => f.criterion)
    .filter((c) => isLeaf(p, c.id));
}

/** id and every criterion below it. */
export function descendants(p: Project, id: string): string[] {
  const out = [id];
  for (let i = 0; i < out.length; i++) {
    for (const c of p.criteria) if (c.parentId === out[i]) out.push(c.id);
  }
  return out;
}

/** A sibling group whose members are compared pairwise: the top level or a criterion's children. */
export interface Group {
  parentId: string; // '' for the top level
  items: Criterion[];
}

/** Sibling groups with at least two members, top level first, in depth-first order. */
export function groups(p: Project): Group[] {
  const parents = ['', ...flatten(p).map((f) => f.criterion.id)];
  return parents
    .map((parentId) => ({ parentId, items: childrenOf(p, parentId) }))
    .filter((g) => g.items.length >= 2);
}

/** Names from the top down to id: ["Technical", "Performance"]. */
export function path(p: Project, id: string): string[] {
  const byId = new Map(p.criteria.map((c) => [c.id, c]));
  const out: string[] = [];
  for (let c = byId.get(id); c; c = c.parentId ? byId.get(c.parentId) : undefined) out.unshift(c.name);
  return out;
}
```

```ts
// Pure edits to a project document. Each function changes p in place, the
// same way the server's Prepare would leave it, so the UI never shows data the
// server is about to drop.
import { snap } from './scale';
import { childrenOf, descendants } from './tree';
import type { Alternative, Criterion, Direction, Evaluator, Method, Project, Scale } from './types';

export const SERIES_SLOTS = 8;

/** A short random id for an item inside a project (like model.NewID). */
export function newId(): string {
  const alphabet = 'abcdefghijklmnopqrstuvwxyz234567';
  const bytes = crypto.getRandomValues(new Uint8Array(8));
  return Array.from(bytes, (b) => alphabet[b % 32]).join('');
}

export const criteriaContext = (parentId = '') => `criteria:${parentId || 'root'}`;
export const altsContext = (criterionId: string) => `alts:${criterionId}`;

// Alternatives

/** Adds an alternative with the first unused series color ('' after eight). */
export function addAlternative(p: Project, name: string): Alternative {
  const used = new Set(p.alternatives.map((a) => a.color));
  let color = '';
  for (let k = 1; k <= SERIES_SLOTS && !color; k++) if (!used.has(`series-${k}`)) color = `series-${k}`;
  const a: Alternative = { id: newId(), name: name.trim(), description: '', color };
  p.alternatives.push(a);
  return a;
}

export function removeAlternative(p: Project, id: string): void {
  p.alternatives = p.alternatives.filter((a) => a.id !== id);
  p.pairwise = p.pairwise.filter((j) => !(j.context.startsWith('alts:') && (j.a === id || j.b === id)));
  p.ratings = p.ratings.filter((r) => r.alternativeId !== id);
  p.values = p.values.filter((v) => v.alternativeId !== id);
}

// Criteria

export function addCriterion(p: Project, name: string, parentId = ''): Criterion {
  const c: Criterion = { id: newId(), name: name.trim(), description: '', notes: '', method: 'pairwise' };
  if (parentId) c.parentId = parentId;
  p.criteria.push(c);
  pruneJudgments(p);
  return c;
}

/** Removes a criterion, everything below it, and every judgment that refers to them. */
export function removeCriterion(p: Project, id: string): void {
  const gone = new Set(descendants(p, id));
  p.criteria = p.criteria.filter((c) => !gone.has(c.id));
  p.ratings = p.ratings.filter((r) => !gone.has(r.criterionId));
  p.values = p.values.filter((v) => !gone.has(v.criterionId));
  pruneJudgments(p);
}

export type Placement = 'before' | 'after' | 'inside';

/**
 * Moves criterion id relative to target: as its previous or next sibling, or
 * as its last child. Returns false (and changes nothing) for a move into its
 * own subtree.
 */
export function moveCriterion(p: Project, id: string, targetId: string, where: Placement): boolean {
  if (descendants(p, id).includes(targetId)) return false;
  const moving = p.criteria.find((c) => c.id === id);
  const target = p.criteria.find((c) => c.id === targetId);
  if (!moving || !target) return false;
  p.criteria = p.criteria.filter((c) => c.id !== id);
  setParent(moving, where === 'inside' ? target.id : (target.parentId ?? ''));
  let at = p.criteria.indexOf(target);
  if (where !== 'before') at += 1;
  if (where === 'inside') {
    // after the target's current last child, so it lands at the end
    const kids = childrenOf(p, target.id);
    if (kids.length) at = p.criteria.indexOf(kids[kids.length - 1]) + 1;
  }
  p.criteria.splice(at, 0, moving);
  pruneJudgments(p);
  return true;
}

/** Makes a criterion the last child of its previous sibling. */
export function indent(p: Project, id: string): boolean {
  const c = p.criteria.find((x) => x.id === id);
  if (!c) return false;
  const sibs = childrenOf(p, c.parentId ?? '');
  const i = sibs.indexOf(c);
  return i > 0 && moveCriterion(p, id, sibs[i - 1].id, 'inside');
}

/** Makes a criterion the next sibling of its parent. */
export function outdent(p: Project, id: string): boolean {
  const c = p.criteria.find((x) => x.id === id);
  return !!c?.parentId && moveCriterion(p, id, c.parentId, 'after');
}

/** Swaps a criterion with its previous (-1) or next (+1) sibling. */
export function shift(p: Project, id: string, dir: -1 | 1): boolean {
  const c = p.criteria.find((x) => x.id === id);
  if (!c) return false;
  const sibs = childrenOf(p, c.parentId ?? '');
  const other = sibs[sibs.indexOf(c) + dir];
  if (!other) return false;
  const i = p.criteria.indexOf(c);
  const j = p.criteria.indexOf(other);
  [p.criteria[i], p.criteria[j]] = [p.criteria[j], p.criteria[i]];
  return true;
}

function setParent(c: Criterion, parentId: string) {
  if (parentId) c.parentId = parentId;
  else delete c.parentId;
}

export function setMethod(p: Project, id: string, method: Method): void {
  const c = p.criteria.find((x) => x.id === id);
  if (!c) return;
  c.method = method;
  if (method === 'value') c.direction ??= 'higher';
}

export function setDirection(p: Project, id: string, direction: Direction): void {
  const c = p.criteria.find((x) => x.id === id);
  if (c) c.direction = direction;
}

/**
 * Drops pairwise judgments whose context no longer exists or whose items are
 * no longer siblings in it (mirrors the server's prune). Judgments of
 * alternatives survive while their criterion exists, even if it gains children.
 */
export function pruneJudgments(p: Project): void {
  const crit = new Map(p.criteria.map((c) => [c.id, c]));
  const alts = new Set(p.alternatives.map((a) => a.id));
  const evals = new Set(p.evaluators.map((e) => e.id));
  p.pairwise = p.pairwise.filter((j) => {
    if (!evals.has(j.evaluatorId) || j.a === j.b) return false;
    const [kind, id] = j.context.split(':');
    if (kind === 'alts') return crit.has(id) && alts.has(j.a) && alts.has(j.b);
    const parent = id === 'root' ? '' : id;
    if (parent && !crit.has(parent)) return false;
    return (crit.get(j.a)?.parentId ?? '') === parent && (crit.get(j.b)?.parentId ?? '') === parent && crit.has(j.a) && crit.has(j.b);
  });
}

// Judgments

/** How strongly a is preferred over b, or undefined if the pair isn't judged. */
export function getJudgment(p: Project, evaluatorId: string, context: string, a: string, b: string): number | undefined {
  for (const j of p.pairwise) {
    if (j.evaluatorId !== evaluatorId || j.context !== context) continue;
    if (j.a === a && j.b === b) return j.value;
    if (j.a === b && j.b === a) return 1 / j.value;
  }
  return undefined;
}

/** Records (or with undefined, clears) how strongly a is preferred over b. */
export function setJudgment(p: Project, evaluatorId: string, context: string, a: string, b: string, value: number | undefined): void {
  p.pairwise = p.pairwise.filter(
    (j) => !(j.evaluatorId === evaluatorId && j.context === context && ((j.a === a && j.b === b) || (j.a === b && j.b === a))),
  );
  if (value !== undefined) p.pairwise.push({ evaluatorId, context, a, b, value });
}

export function getRating(p: Project, evaluatorId: string, criterionId: string, alternativeId: string): number | undefined {
  return p.ratings.find((r) => r.evaluatorId === evaluatorId && r.criterionId === criterionId && r.alternativeId === alternativeId)?.value;
}

export function setRating(p: Project, evaluatorId: string, criterionId: string, alternativeId: string, value: number | undefined): void {
  p.ratings = p.ratings.filter((r) => !(r.evaluatorId === evaluatorId && r.criterionId === criterionId && r.alternativeId === alternativeId));
  if (value !== undefined) p.ratings.push({ evaluatorId, criterionId, alternativeId, value });
}

export function getValue(p: Project, criterionId: string, alternativeId: string): number | undefined {
  return p.values.find((v) => v.criterionId === criterionId && v.alternativeId === alternativeId)?.value;
}

export function setValue(p: Project, criterionId: string, alternativeId: string, value: number | undefined): void {
  p.values = p.values.filter((v) => !(v.criterionId === criterionId && v.alternativeId === alternativeId));
  if (value !== undefined && Number.isFinite(value)) p.values.push({ criterionId, alternativeId, value });
}

export function addEvaluator(p: Project, name: string): Evaluator {
  const e: Evaluator = { id: newId(), name: name.trim(), weight: 1 };
  p.evaluators.push(e);
  return e;
}
```

```ts
/** An unordered pair of item indices, i < j. */
export type Pair = [number, number];

/**
 * The order in which the one-pair-at-a-time view asks about n items. First a
 * chain that links every item (so results exist after only n−1 answers), then
 * the remaining pairs, closest in current weight first: those are the ones
 * where another answer changes the ranking most.
 */
export function focusOrder(n: number, weights?: number[] | null): Pair[] {
  const chain: Pair[] = [];
  for (let i = 1; i < n; i++) chain.push([i - 1, i]);
  const rest: Pair[] = [];
  for (let i = 0; i < n; i++) for (let j = i + 2; j < n; j++) rest.push([i, j]);
  if (weights && weights.length === n) {
    const gap = ([i, j]: Pair) => Math.abs(Math.log(weights[i] / weights[j]));
    rest.sort((x, y) => gap(x) - gap(y) || x[0] - y[0] || x[1] - y[1]);
  }
  return [...chain, ...rest];
}

/** n·(n−1)/2: the number of pairs among n items. */
export const pairCount = (n: number) => (n * (n - 1)) / 2;
```

```ts
import { altsContext, criteriaContext, getJudgment, getRating, getValue } from './edits';
import { pairCount } from './pairs';
import { groups, leaves } from './tree';
import type { Criterion, Project } from './types';

export interface Progress {
  done: number;
  total: number;
}

/** How many of the comparisons in one pairwise context an evaluator has made. */
export function pairProgress(p: Project, evaluatorId: string, context: string, items: string[]): Progress {
  let done = 0;
  for (let i = 0; i < items.length; i++)
    for (let j = i + 1; j < items.length; j++) if (getJudgment(p, evaluatorId, context, items[i], items[j]) !== undefined) done++;
  return { done, total: pairCount(items.length) };
}

/** Progress on one leaf criterion, by its scoring method. Measured values are shared, not per evaluator. */
export function leafProgress(p: Project, evaluatorId: string, c: Criterion): Progress {
  const alts = p.alternatives.map((a) => a.id);
  if (c.method === 'rating') return { done: alts.filter((a) => getRating(p, evaluatorId, c.id, a) !== undefined).length, total: alts.length };
  if (c.method === 'value') return { done: alts.filter((a) => getValue(p, c.id, a) !== undefined).length, total: alts.length };
  return pairProgress(p, evaluatorId, altsContext(c.id), alts);
}

/** Progress weighing criteria: every sibling group's comparisons. */
export function weighProgress(p: Project, evaluatorId: string): Progress {
  return sum(groups(p).map((g) => pairProgress(p, evaluatorId, criteriaContext(g.parentId), g.items.map((c) => c.id))));
}

/** Progress scoring alternatives on every leaf. */
export function scoreProgress(p: Project, evaluatorId: string): Progress {
  return sum(leaves(p).map((c) => leafProgress(p, evaluatorId, c)));
}

function sum(ps: Progress[]): Progress {
```

```ts
// Mirrors internal/ahp/sensitivity.go so the sensitivity slider can redraw
// without a round trip. Parity with Go is checked against the golden files in
// internal/model/testdata/golden (see sensitivity.test.ts).
import type { Results } from './types';

/** Each alternative's overall score as intercept + slope·x, where x is one criterion's local weight. */
export interface Line {
  intercept: number[];
  slope: number[];
}

export const at = (l: Line, x: number) => l.intercept.map((c, a) => c + l.slope[a] * x);

/**
 * The scores as a function of criterion id's local weight, with its siblings
 * rescaled to share the rest (equally, if they currently have no weight).
 * Null when the criterion has no siblings.
 */
export function lineFor(r: Results, id: string): Line | null {
  const node = r.criteria.find((c) => c.id === id);
  if (!node) return null;
  const parentId = node.parentId ?? '';
  const sibs = r.criteria.filter((c) => c.id !== id && (c.parentId ?? '') === parentId);
  if (sibs.length === 0) return null;
  const gp = parentId ? (r.criteria.find((c) => c.id === parentId)?.global ?? 0) : 1;
  const w = node.local;
  const line: Line = { intercept: [], slope: [] };
  r.scores.forEach((s, a) => {
    let others = 0;
    for (const sb of sibs) others += sb.local * sb.subtree[a];
    const group = w * node.subtree[a] + others;
    let q: number;
    if (1 - w > 1e-12) q = others / (1 - w);
    else q = sibs.reduce((t, sb) => t + sb.subtree[a], 0) / sibs.length;
    const rest = s.score - gp * group;
    line.intercept.push(rest + gp * q);
    line.slope.push(gp * (node.subtree[a] - q));
  });
  return line;
}

/** The weight in [0, 1] where alternatives a and b score equally, if any. */
function meet(l: Line, a: number, b: number): number | null {
  const ds = l.slope[a] - l.slope[b];
  if (Math.abs(ds) < 1e-15) return null;
  const x = (l.intercept[b] - l.intercept[a]) / ds;
  return x >= 0 && x <= 1 ? x : null;
}

export interface Crossover {
  x: number;
  a: number;
  b: number;
}

/** Every weight in [0, 1] where two alternatives swap places, sorted by weight. */
export function crossovers(l: Line): Crossover[] {
  const out: Crossover[] = [];
  for (let a = 0; a < l.slope.length; a++)
    for (let b = a + 1; b < l.slope.length; b++) {
      const x = meet(l, a, b);
      if (x !== null) out.push({ x, a, b });
    }
  return out.sort((p, q) => p.x - q.x);
}

const argmax = (v: number[]) => v.reduce((best, x, i) => (x > v[best] ? i : best), 0);

/** The smallest change from weight w at which the leader changes, or null if it never does. */
export function stability(l: Line, w: number): number | null {
  const top = argmax(at(l, w));
  let best: number | null = null;
  for (let b = 0; b < l.slope.length; b++) {
    if (b === top) continue;
    const x = meet(l, top, b);
    if (x !== null && (best === null || Math.abs(x - w) < best)) best = Math.abs(x - w);
  }
  return best;
}

/** The index of the leading alternative at weight x. */
export const leaderAt = (l: Line, x: number) => argmax(at(l, x));
```

```ts
import { ApiError, api, type Client } from './api';
import { ALL_EVALUATORS, type Project, type Results } from './types';

export type SaveState = 'saved' | 'pending' | 'saving' | 'conflict' | 'error';

/**
 * One open project. Edits change `project` in place and call `changed()`;
 * the session saves 600 ms after the last edit, keeps the local copy as the
 * source of truth (only the version comes back from the server), and fetches
 * fresh results after each save.
 */
export class ProjectSession {
  project: Project = $state()!;
  saveState: SaveState = $state('saved');
  error = $state('');
  /** Evaluator whose judgments the compare screens edit. */
  scoringAs = $state('');
  /** Latest results, keyed by evaluator id or ALL_EVALUATORS. */
  results: Record<string, Results> = $state({});

  private timer: ReturnType<typeof setTimeout> | undefined;
  private inFlight: Promise<void> | null = null;
  private watched = new Set<string>([ALL_EVALUATORS]);

  constructor(
    project: Project,
    private client: Client = api,
    private delayMs = 600,
  ) {
    this.project = project;
    this.scoringAs = project.evaluators[0]?.id ?? '';
  }

  static async open(id: string, client: Client = api): Promise<ProjectSession> {
    const s = new ProjectSession(await client.getProject(id), client);
    await s.refreshResults();
    return s;
  }

  /** Call after every edit to project. */
  changed(): void {
    if (this.saveState === 'conflict') return; // wait for the person to choose
    this.saveState = 'pending';
    clearTimeout(this.timer);
    this.timer = setTimeout(() => void this.flush(), this.delayMs);
  }

  /** Saves now if there are unsaved edits; resolves when saving is done. */
  async flush(): Promise<void> {
    clearTimeout(this.timer);
    if (this.inFlight) await this.inFlight;
    if (this.saveState !== 'pending') return;
    this.inFlight = this.save();
    try {
      await this.inFlight;
    } finally {
      this.inFlight = null;
    }
  }

  private async save(): Promise<void> {
    this.saveState = 'saving';
    const sent = $state.snapshot(this.project) as Project;
    try {
      const saved = await this.client.saveProject(sent);
      this.project.version = saved.version;
      this.project.updatedAt = saved.updatedAt;
      // Edits made while saving left the state 'pending'; save those too.
      if (this.saveState === 'saving') this.saveState = 'saved';
      else this.timer = setTimeout(() => void this.flush(), this.delayMs);
      this.error = '';
      await this.refreshResults();
    } catch (e) {
      if (e instanceof ApiError && e.code === 'conflict') {
        this.saveState = 'conflict';
        this.error = 'This project was changed in another window.';
      } else {
        this.saveState = 'error';
        this.error = e instanceof Error ? e.message : String(e);
      }
    }
  }

  /** Also keep results for this evaluator fresh after each save. */
  watch(evaluator: string): void {
    if (this.watched.has(evaluator)) return;
    this.watched.add(evaluator);
    void this.refreshResults([evaluator]);
  }

  async refreshResults(evaluators: string[] = [...this.watched]): Promise<void> {
    const known = new Set([ALL_EVALUATORS, ...this.project.evaluators.map((e) => e.id)]);
    await Promise.all(
      evaluators
        .filter((ev) => known.has(ev))
        .map(async (ev) => {
          try {
            this.results[ev] = await this.client.results(this.project.id, ev);
          } catch {
            // Results are advisory; the next save tries again.
          }
        }),
    );
  }

  /** Conflict resolution: discard local edits and load the stored project. */
  async reload(): Promise<void> {
    clearTimeout(this.timer);
    this.project = await this.client.getProject(this.project.id);
    if (!this.project.evaluators.some((e) => e.id === this.scoringAs)) this.scoringAs = this.project.evaluators[0]?.id ?? '';
    this.saveState = 'saved';
    this.error = '';
    await this.refreshResults();
  }

  /** Conflict resolution: keep local edits and replace the stored project. */
  async overwrite(): Promise<void> {
    const stored = await this.client.getProject(this.project.id);
    this.project.version = stored.version;
    this.saveState = 'pending';
    await this.flush();
  }

  /** Retry after an error. */
  retry(): Promise<void> {
    this.saveState = 'pending';
    return this.flush();
  }
}
```

```svelte
  import type { Scale } from '../lib/types';
```

```svelte
  // judging as: one pair on the balance (Focus) or all pairs at once (Grid).
  import { getJudgment, setJudgment } from '../lib/edits';
  import { focusOrder, type Pair } from '../lib/pairs';
  import { pairProgress } from '../lib/progress';
  import type { CompareKind } from '../lib/scale';
  import type { ProjectSession } from '../lib/session.svelte';
  import Balance from './Balance.svelte';
  import ConsistencyMeter from './ConsistencyMeter.svelte';
  import MatrixGrid from './MatrixGrid.svelte';

  export interface Item {
    id: string;
    name: string;
    color?: string;
  }

  let {
    session,
    context,
    items,
    kind,
    on = '',
  }: { session: ProjectSession; context: string; items: Item[]; kind: CompareKind; on?: string } = $props();

  const p = $derived(session.project);
  const ev = $derived(session.scoringAs);
  $effect(() => session.watch(ev));

  const report = $derived(session.results[ev]?.matrices.find((m) => m.context === context));
  const ids = $derived(items.map((i) => i.id));
  const progress = $derived(pairProgress(p, ev, context, ids));

  let mode = $state<'focus' | 'grid'>('focus');
  // The order is fixed when the view opens (re-sorting while answering would be disorienting).
  let order = $state<Pair[]>([]);
  let at = $state(0);
  let orderKey = '';

  $effect(() => {
    const key = `${context}|${ids.join(',')}|${ev}`;
    if (key === orderKey) return;
    orderKey = key;
    order = focusOrder(items.length, report?.weights);
    const firstOpen = order.findIndex(([i, j]) => value(i, j) === undefined);
    at = firstOpen < 0 ? 0 : firstOpen;
  });

  const value = (i: number, j: number) => getJudgment(p, ev, context, ids[i], ids[j]);
  const current = $derived(order[at]);

  function set(i: number, j: number, v: number | undefined) {
    setJudgment(session.project, ev, context, ids[i], ids[j], v);
    session.changed();
  }

  function next() {
    const after = order.findIndex(([i, j], k) => k > at && value(i, j) === undefined);
    at = after >= 0 ? after : Math.min(at + 1, order.length - 1);
  }

  function onKey(e: KeyboardEvent) {
    if (mode !== 'focus' || (e.target as HTMLElement).closest('input,select,textarea')) return;
    if (e.key === 'Enter') {
      e.preventDefault();
      next();
    } else if (e.key === 's' || e.key === 'S') {
      at = Math.min(at + 1, order.length - 1);
    }
  }

  function fix(a: string, b: string, v: number) {
    setJudgment(session.project, ev, context, a, b, v);
    session.changed();
  }
</script>
```

```svelte
<script lang="ts">
  // Each option's overall score as one criterion's weight goes from 0 to 100%.
  // Lines are straight (the scores are linear in the weight). A dashed marker
  // shows the current weight, a solid one the what-if weight, and dots mark
  // where the ranking changes. Hover shows every score at that weight.
  import { percent } from '../../lib/format';
  import { at, crossovers, type Line } from '../../lib/sensitivity';

  let {
    line,
    names,
    colors,
    current,
    x,
  }: { line: Line; names: string[]; colors: string[]; current: number; x: number } = $props();

  const W = 640;
  const H = 300;
  const pad = { l: 48, r: 150, t: 16, b: 34 };
  const iw = W - pad.l - pad.r;
  const ih = H - pad.t - pad.b;

  const ends = $derived([at(line, 0), at(line, 1)]);
  const lo = $derived(Math.max(0, Math.min(...ends[0], ...ends[1]) - 0.02));
  const hi = $derived(Math.min(1, Math.max(...ends[0], ...ends[1]) + 0.02));
  const sx = (v: number) => pad.l + v * iw;
  const sy = $derived((v: number) => pad.t + (1 - (v - lo) / (hi - lo || 1)) * ih);
  const ticks = $derived(Array.from({ length: 5 }, (_, k) => lo + ((hi - lo) * k) / 4));
  const cross = $derived(crossovers(line));
  const direct = $derived(names.length <= 4);

  // Direct labels at the right end, nudged apart so they don't collide.
  const labels = $derived.by(() => {
    const ys = ends[1].map((v, a) => ({ a, y: sy(v) })).sort((p, q) => p.y - q.y);
    for (let k = 1; k < ys.length; k++) ys[k].y = Math.max(ys[k].y, ys[k - 1].y + 15);
    return ys;
  });

  let hover = $state<number | null>(null);
  let svg = $state<SVGSVGElement | undefined>();
  function move(e: PointerEvent) {
    if (!svg) return;
    const r = svg.getBoundingClientRect();
    const v = ((e.clientX - r.left) * (W / r.width) - pad.l) / iw;
    hover = v >= 0 && v <= 1 ? v : null;
  }
  const hoverRows = $derived(
    hover === null ? [] : at(line, hover).map((s, a) => ({ a, s })).sort((p, q) => q.s - p.s),
```

```ts
export type Step = 'setup' | 'weigh' | 'score' | 'results' | 'sensitivity';
export const STEPS: Step[] = ['setup', 'weigh', 'score', 'results', 'sensitivity'];

export type Route = { name: 'library' } | { name: 'project'; id: string; step: Step; sub: string } | { name: 'report'; id: string };

/** Parses a hash path: "/", "/p/<id>/<step>[/<sub>]" or "/p/<id>/report". */
export function parse(path: string): Route {
  const parts = path.replace(/^#?\/?/, '').split('/').map(decodeURIComponent);
  if (parts[0] === 'p' && parts[1]) {
    if (parts[2] === 'report') return { name: 'report', id: parts[1] };
    const step = (STEPS as string[]).includes(parts[2]) ? (parts[2] as Step) : 'setup';
    return { name: 'project', id: parts[1], step, sub: parts[3] ?? '' };
  }
  return { name: 'library' };
}

export const href = (id: string, step: Step | 'report' = 'setup', sub = '') =>
  `#/p/${encodeURIComponent(id)}/$13${sub ? `/${encodeURIComponent(sub)}` : ''}`;

class Router {
  route: Route = $state(parse(location.hash));
  constructor() {
    window.addEventListener('hashchange', () => (this.route = parse(location.hash)));
  }
  go(hash: string) {
    location.hash = hash;
  }
}

export const router = new Router();
```

```svelte
  // (which reads from the server) never shows stale data.
  let settled = $state(true);

  const projectId = $derived(router.route.name === 'library' ? '' : router.route.id);

    }
    if (!id) {

      return;

    if (previous?.project.id === id) return;
    loadError = '';
    session = null;
    leaving.then(() => ProjectSession.open(id)).then(
      (s) => {
        if (projectId === id) session = s;
      },
      (e) => (loadError = e instanceof Error ? e.message : String(e)),
    );
  });

  // A new screen starts at the top, like a page load would.
  $effect(() => {
    void router.route;
    window.scrollTo(0, 0);
  });

  function beforeUnload(e: BeforeUnloadEvent) {
    if (session && (session.saveState === 'pending' || session.saveState === 'saving')) {
      void session.flush();
      e.preventDefault();
    }
  }
</script>

<svelte:window onbeforeunload={beforeUnload} />

  <main class="message" aria-busy="true"><p class="muted">Saving…</p></main>
{:else if router.route.name === 'library'}
  <Library />
{:else if loadError}

{:else if !session}

{:else if router.route.name === 'report'}

{:else}

{/if}
```

````markdown
# AHP Matrix

Make better decisions with the [Analytic Hierarchy Process](https://en.wikipedia.org/wiki/Analytic_hierarchy_process):
compare your options two at a time, check that your judgments agree with each other, and see how robust the winner is.
AHP Matrix is a single binary that runs a local web app. Your projects stay on your machine as `.ahp.json` files.

![Comparing two criteria on the balance](docs/images/compare.jpg)

- **Compare in pairs on a balance.** Arrow keys tip it, Enter moves to the next pair, and you get useful results long before every pair is answered.
- **Rate or measure where pairs are overkill.** Each criterion can be compared in pairs, rated 1–10, or given measured values such as price ("lower is better").
- **Group criteria** into a hierarchy, so you only compare criteria that belong together.
- **Catch contradictions.** Every set of comparisons gets a consistency ratio, and the app points out the answers that disagree with the rest, with a one-click fix.
- **Several people.** Everyone judges separately, the results combine them (weighted), and the app shows where people disagree most.
- **What if?** Drag a criterion's weight and watch the ranking change. Each criterion shows how far it can move before the winner changes.

![Results for a laptop decision](docs/images/results.jpg)

> **Status:** early development. Excel import/export, sample projects and release binaries are next.

## Run it

Requires Go 1.24+ and Node 20.19+ to build from source.

```sh
git clone https://github.com/Xafloc/ahp-matrix && cd ahp-matrix
make run    # builds the UI and the binary, starts on http://127.0.0.1:7777 and opens your browser
```

`bin/ahp-matrix --help` lists the flags (`--port`, `--host`, `--data-dir`, `--no-open`).
Projects are stored in `~/Library/Application Support/ahp-matrix` (macOS),
`%AppData%\ahp-matrix` (Windows) or `~/.local/share/ahp-matrix` (Linux) unless `--data-dir` is given.
````
